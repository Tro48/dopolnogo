# До полного — Telegram Mini App

Сервис заправки автомобиля по поручению: клиент оставляет заявку, исполнитель
приезжает, едет на АЗС **на машине клиента и заправляет её деньгами клиента**,
присылает фото чека.

> **Демонстрационный проект.** Заявки и исполнители вымышленные, оплата не
> подключена, реальную заправку заказать нельзя.
>
> Статус: в разработке.

## Границы продукта

Они заданы намеренно, и это часть архитектуры, а не оговорка мелким шрифтом:

- топливо **не перепродаётся** — его покупает владелец машины на колонке своей картой;
- бензин **не возится в канистрах**;
- лимиты на АЗС **не обходятся** — заправляется тот же автомобиль, который
  заправился бы и сам.

Продаётся время человека, стоящего в очереди, а не бензин.

## Что здесь показано технически

- **Проверка `initData` от Telegram по HMAC на сервере.** Место, где обычно
  доверяют клиенту: подменил `user.id` в теле запроса — стал модератором.
  Проверяется подпись, `auth_date` (окно 24 ч) и сравнение в постоянном времени.
- **Роль берётся из базы по `tg_id`**, а не из тела запроса и не из `initData`.
- **Ролевая модель поверх RLS**, а не `if (isAdmin)` в компоненте.
- **Атомарный переход статуса**: `update … where id = $1 and status = 'new'`.
  Ноль строк в ответе — заявку уже забрали. Проверка `if (order.status === 'new')`
  в коде приложения от гонки двух исполнителей не спасает.
- **Аудит переходов** в отдельной таблице, в той же транзакции.
- **Идемпотентные уведомления**: `dedup_key` с уникальным индексом, повторная
  отправка при ретрае падает на нём — и это правильное поведение.
- **Точный адрес не уходит исполнителю до принятия заявки** — отдельной вьюхой,
  а не скрытием на клиенте.
- Mini App следует теме клиента Telegram: свои цвета только у акцента и статусов.

## Стек

Next.js (App Router) · TypeScript · Tailwind CSS · Motion · Zustand ·
TanStack Query · Zod · Supabase · Vitest · Playwright · Vercel

## Как запустить

```bash
pnpm install
cp .env.example .env.local   # и заполнить
pnpm dev
```

Токен бота получают в [@BotFather](https://t.me/BotFather). `SESSION_SECRET`
генерируется через `openssl rand -base64 32`.
