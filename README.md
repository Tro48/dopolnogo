# Стапель — студия фронтенд-разработки

Лендинг, продающий услуги фронтенд-разработки на React и Next.js.
В отличие от двух других работ портфолио, **это не демо**: услуги, процесс и стек
настоящие. Вымышлено только название бренда. Статус каждого кейса помечен честно —
демо-проекты обозначены как демо.

> Статус: каркас репозитория. Разработка не начата.
> План реализации — [`docs/plan.md`](./docs/plan.md).
>
> Перед деплоем заменить плейсхолдеры контактов на настоящие и убрать этот блок.

## О проекте

Стапель — конструкция, на которой строят и с которой спускают на воду корабль.
Не сам корабль: опора, на которой он собирается. Точная метафора работы подрядчика.

Позиционирование: «Фронтенд под ключ на React и Next.js. Собираю то, что потом можно
поддерживать» — вторая строка бьёт в реальную боль заказчика, у которого предыдущий
подрядчик оставил неподдерживаемый код.

Визуальная идея — **чертёж**: тёмный фон, едва заметная координатная сетка,
моноширинные выноски у секций, размерные линии. Один кислотный акцент на всю
страницу. Дизайн, который сам является аргументом.

## Что здесь показано технически

Самый нагруженный проект портфолио.

- **Multi-step форма брифинга** с валидацией по шагам, персистом черновика,
  восстановлением после перезагрузки и корректной клавиатурой.
- **Контакты собираются на первом шаге, не на последнем.** Человек, дошедший до
  поля «телефон» на третьем шаге, пугается звонка и закрывает вкладку — а вы даже
  не знаете, что он приходил.
- **Прогрессивное сохранение**: после первого шага бриф уже лежит в базе со
  статусом `draft`. Бросил на втором — контакт остался, и видно, где отвалился.
- **Zustand + persist в `sessionStorage`**, не `localStorage`: черновик с телефоном
  и бюджетом не должен лежать на общем компьютере месяцами. Гидратация персиста
  обработана флагом `hasHydrated` — без него форма мигает при загрузке.
- **TanStack Query с префетчем в RSC**: кейсы приходят в первом HTML-ответе, без
  спиннера, дальше клиент фильтрует из кеша.
- **URL — источник истины для фильтров.** `/?tag=saas` можно переслать, кнопка
  «назад» работает.
- Условная обязательность полей через `.refine()` с `path` — и то же самое
  проверяется на сервере, потому что клиент мог отправить запрос в обход шагов.

## Как начать

Репозиторий пока содержит только документацию и конфигурацию. Скаффолд:

```bash
pnpm create next-app@latest . --typescript --tailwind --app --eslint --src-dir
cp .env.example .env.local   # и заполнить
pnpm dev
```

Проект делается последним из трёх: он переиспользует лайтбокс, примитивы UI и
модуль отправки в Telegram из предыдущих работ.
